skill /graphify
USER · ~/.claude/skills · enabled ● · invoked via Skill tool · no conflicts
Summary

Turns any input — code, docs, papers, images — into a knowledge graph: extracts entities and relationships, clusters them into communities, and emits an interactive HTML view, a JSON graph, and an audit report.

Trigger & behavior

Runs when the user types /graphify, or proactively when a request matches its description. Defined in the user's global skills directory, so it is available across all projects.
